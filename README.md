# Student-management-system
 Student Management System

A simple Student Management System built using Python.
This project helps manage student records such as names, roll numbers, marks, grades, and other basic information.

 Features

- Add new student
-  Display all students
-  Search student by roll number
-  Update student details
-  Delete student record
-  Calculate marks and grades
-  Exit the program
-  Simple command-line interface

Technologies Used

- Python 3
- Variables
- Lists / Dictionaries
- Functions
- Conditional statements
- Loops
- User input
- Basic file handling (if included in your version)
